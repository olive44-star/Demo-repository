# EvaeXtra.com Mentorship Scheme

Welcome to the EvaeXtra.com Mentorship Scheme landing page. This is a simple, lightweight animated website project designed for beginners.

## Files Included
- `index.html`: The main web page structure.
- `styles.css`: Visual styling and CSS animations.
- `scripts.js`: JavaScript for user interaction.
- `README.md`: Documentation for the project.

## How to use
Simply clone this repository and open `index.html` in your favorite web browser to view the animated landing page!
